# Soumly — Comparateur de prix en Tunisie

واجهة كاملة ومتجاوبة لموقع **Soumly** باللغة الفرنسية، مستوحاة من تنظيم وتجربة مواقع مقارنة الأسعار مع الحفاظ على الهوية البنفسجية والحمراء المعتمدة.

## محتويات الملف

- `app/`: الصفحة الرئيسية والمظهر والتفاعلات.
- `public/assets/`: صور المنتجات والواجهة.
- `dist/`: نسخة الإنتاج الجاهزة التي تم بناؤها والتحقق منها.
- `references/`: صورتا المرجع للحاسوب والهاتف.
- البحث، اقتراحات المنتجات، الفلاتر، المفضلة، القوائم الأفقية، ونافذة مقارنة الأسعار.
- تصميم Mobile-first مناسب لمقاسات 360 و390 و430 بكسل، ومتجاوب مع الحاسوب.

## التشغيل محليًا

يتطلب Node.js 22.13 أو أحدث.

```bash
npm install
npm run dev
```

ثم افتح العنوان المحلي الذي يظهر في الطرفية.

## التعديل السريع

- المنتجات والأسعار والمتاجر موجودة في `app/page.tsx`.
- الألوان والمسافات ومقاسات الهاتف والحاسوب موجودة في `app/globals.css`.
- الصور موجودة في `public/assets/`.

## ملاحظة

الأسعار والعروض داخل النموذج بيانات تجريبية للعرض فقط. اربط الصفحة ببيانات المتاجر الحقيقية قبل الإطلاق العام. قيمة `project_id` داخل ملف الاستضافة هي قيمة مؤقتة ويجب استبدالها عند ربط المشروع بخدمة استضافة جديدة.
