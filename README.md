# Soumly — Comparateur de prix en Tunisie

نسخة متكاملة من موقع Soumly باللغة الفرنسية، تحافظ على التصميم الأصلي وتربط صفحات الكتالوج والبحث والمقارنة والمفضلة والأدلة والصفحات القانونية.

## ما الذي يتضمنه المشروع؟

- 1,573 منتجًا بعد إزالة السجلات المتكررة.
- 9 أقسام صحيحة بالفرنسية.
- عروض حقيقية مستوردة من Tunisianet وSpacenet فقط.
- صفحة خاصة لكل منتج تعرض أسعار المتاجر من الأرخص إلى الأغلى.
- إبراز أقل سعر مع زر مباشر إلى صفحة المنتج لدى المتجر.
- حالات واضحة عندما يوجد متجر واحد أو أكثر من متجر.
- بحث وفلاتر للسعر والعلامة التجارية والعروض.
- مفضلة وتنبيهات محفوظة محليًا على الجهاز.
- صفحات المتاجر، الأدلة، الحساب المحلي، الخصوصية، الشروط والبيانات القانونية.
- تصميم متجاوب للحاسوب والهاتف.
- صفحات خطأ وتحميل و404، وعناوين SEO ديناميكية.

## التشغيل محليًا

المتطلبات: Node.js 22.13 أو أحدث.

```bash
npm ci
npm run dev
```

يفتح خادم التطوير افتراضيًا على المنفذ `5173`.

## التحقق والبناء الإنتاجي

```bash
npm run lint
npx tsc --noEmit
npm run build
node --test tests/rendered-html.test.mjs
npm audit --omit=dev
```

## التشغيل الإنتاجي

```bash
npm ci
npm run build
PORT=5173 npm run start
```

## Docker

```bash
docker compose build
SOUMLY_DOMAIN=soumly.online docker compose up -d
```

يستخدم التطبيق المنفذ الداخلي `5173`. يتوقع ملف Compose وجود شبكة Traefik خارجية باسم `web`.

## النشر على VPS

انسخ المشروع إلى `/opt/soumly` ثم شغّل:

```bash
sudo SOUMLY_DOMAIN=soumly.online \
  SOUMLY_EMAIL=admin@soumly.online \
  SOUMLY_APP_DIR=/opt/soumly \
  bash deploy/setup-soumly-server.sh
```

السكريبت ينشئ خدمة systemd، ويضبط Nginx وHTTPS.

## مصدر البيانات

البيانات الخام موجودة في `app/products.ts`. طبقة التنظيف والتصنيف والمقارنة موجودة في:

`app/(soumly-pages)/_data/content.ts`

تقوم هذه الطبقة بما يلي:

- تحويل أسعار Tunisianet من المليم إلى الدينار.
- تصحيح الأسعار القديمة غير المنطقية في بيانات Spacenet.
- إزالة المنتجات المكررة.
- الاحتفاظ بعرض واحد مطابق لكل متجر.
- منع الروابط غير الصالحة أو غير التابعة للمتاجر المعروفة.
- عدم اختلاق تقييمات أو مراجعات أو متاجر.

## إعدادات مطلوبة قبل الإطلاق التجاري

1. إضافة الاسم القانوني، العنوان، المعرّف الجبائي وبيانات المسؤول في صفحة `mentions-legales`.
2. إضافة البريد والهاتف الرسميين في صفحة `contact`.
3. إعداد مهمة دورية موثوقة لاستيراد الأسعار ومراقبة فشل الروابط.
4. مراجعة شروط استخدام بيانات كل متجر قبل تشغيل جمع تلقائي جديد.
5. إذا أردت حسابات متزامنة بين الأجهزة، اربط خدمة مصادقة وقاعدة بيانات بدل التخزين المحلي.

راجع `AUDIT-REPORT.md` للحصول على ملخص الفحص والنتائج.
